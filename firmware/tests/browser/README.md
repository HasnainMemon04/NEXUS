# Embedded dashboard browser test

Install Node.js and run the following commands from the repository root in PowerShell.

```powershell
Push-Location firmware/tests/browser
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
Pop-Location
node firmware/tests/browser/smoke.cjs
```

To use an existing Chrome install, set `CHROME_PATH` to its executable and skip the Playwright browser download. The dependency is only needed for the host-side test.

The fixture serves the actual embedded HTML with simulated four-board HTTP, WebSocket, and binary tile data. It checks desktop and phone layouts, zoom and paged tiles, Worker C tile ownership, dual-core monitor rendering, single-core fallback, keyboard focus, and Worker C slot, drain, fault, and lab commands. It also checks benchmark filters and per-executor results, command errors, disconnect feedback, and experiment locking. It fails on unexpected network requests or page errors.

Screenshots and the run summary go to `firmware/test-output/dashboard/`. The displayed values are generated by the fixture.
